What Thursday Drop is:
Thursday Drop is a premium wine release notification service for Ontario LCBO Vintages collectors. LCBO Vintages releases new fine and rare wines on their website every week through three programs — Special Offers, Monthly Cellar Features, and Bordeaux Futures. Allocated bottles sell out within minutes of release. Thursday Drop watches the LCBO Vintages website automatically and sends personalized email alerts to subscribers when wines on their personal watchlist become available.

How it should work — confirm each of these is correctly implemented:

1. SCRAPER
Every Thursday at 9am and 10am Eastern, a cron job automatically visits these three LCBO index pages:
- https://www.vintagesshoponline.com/vintages/SpecialOffer.aspx
- https://www.vintagesshoponline.com/vintages/ClassicsCollection.aspx
- https://www.vintagesshoponline.com/vintages/BordeauxFuture.aspx
It reads all active program links from each page, extracts the programId from each link, then visits each program page at https://www.vintagesshoponline.com/vintages/Public/OrderProgramProducts.aspx?programId=XXXX&lang=en
It handles pagination — if a program has multiple pages it scrapes all of them.
For each wine it captures: wine name, producer, LCBO number, region, region category, vintage year, critic score, score source, price, quantity available, closing date, direct buy URL.
Each program is tagged with its correct source category — special_offers, monthly_collection, or bordeaux_futures.
If a program has already been scraped and exists in the database it is skipped to avoid duplicates.
After scraping, the matching engine runs immediately.

2. MATCHING ENGINE
After every scrape, the system compares every newly scraped wine against every active user watchlist.
There are three match types:
- exact: matches on wine name AND vintage year together
- wine: matches on wine name only, any vintage
- producer: matches on producer name only, any wine
For every match found, an alert row is created in the alerts table with status queued.
Duplicate alerts are never created — if a user already has a queued or sent alert for that wine they do not get another one.

3. ALERT EMAILS
Two emails are sent for each match:
Alert 1 — Announcement alert: sent immediately after the scraper runs. Subject line: [Wine Name] just appeared on Vintages. Body includes: wine name, vintage, producer, region, price, critic score, quantity available, which program it is from (Special Offers / Monthly Collection / Bordeaux Futures), the release opening date, a direct buy link to the LCBO page, and a note saying ordering opens Thursday at 8:30am Eastern.
Alert 2 — Morning reminder: sent at 7am Eastern on the Thursday the wine officially opens for ordering. Subject line: [Wine Name] opens for ordering in 90 minutes. Body includes: same wine details plus urgency messaging that ordering opens at 8:30am and quantities are limited.
A backup morning alert run happens at 8am Eastern in case anything was missed at 7am.
All emails send from alerts@thursdaydrop.ca via Resend.
Every email has an unsubscribe link at the bottom.

4. WATCHLIST
Logged in users can add wines to their watchlist in three ways:
- Track this wine, this vintage only (exact match)
- Track this wine, any vintage (wine match)
- Track any wine by this producer (producer match)
Free tier users are capped at 5 watchlist items.
Pro tier users have unlimited watchlist items.
Users can also track by category — Burgundy Grand Cru, Barolo, Super Tuscans etc — Pro only.
There is a curated list of 40 suggested wines that users can quickly add to their watchlist.

5. RELEASE PAGE
Publicly visible — no login required.
Shows all currently active programs organized into three tabs: Special Offers, Monthly Collection, Bordeaux Futures.

Each program shows: program name, number of wines, closing date, status (Preview or Available), and a link to the program on LCBO Vintages.
Preview programs show a badge saying Opens [date] — users can add to watchlist in advance.
Each wine row has a + button that opens a popover with three tracking options.
